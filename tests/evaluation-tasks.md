# 独立测试任务

## T1 选路与能力边界

分别面对带孔薄壁静态装配、带 UV/法线贴图道具、带骨骼和表情的角色、扫描网格、分块地形和带标签点云：给出合适工具路线、保护属性、计数口径、验证方法。指出随包静态比例脚本可用及应拒绝的输入。工具缺失时继续可执行检查并列出未验部分。

## T2 真正运行工具

运行 Python 单测与合成帧分析。存在 Blender 时执行 blender_smoke.py 并实际重导入产物，检查受保护对象和原件摘要。解释 GLB 声明审计的局限。不把合成测试称为真实设备性能或外观验收。

## T3 计算

两个独立块 [10,10,20] 和 [20,10,10] ms，长帧 >16.67 ms：计算线性 P99、最长连续长帧和平均 FPS。半径 2.5 mm、弦高 <=25 µm，不要求偶数，求最少段数及22/23/24段弦高。唯一网格1000点1000面，10实例，两个子网格各引用600点且重叠200点，分别报唯一、实例与子网格求和。只知一个修复方案的成本，能否证明其他表示皆不可行？

## T4 证据陷阱

判断：隐藏窗口零绘制却超高 FPS；新版本沿用旧原始数据哈希；P99号称线性却取 floor(q*N)；全貌通过但近景失败；截图相同却改 shader 后没测帧；旧局部通过但新孔缘失败；GPU时间全为-1；导出漏 shader include；面数降低但顶点流未压紧；静态角色截图通过却未验动作；点云平均距离低却丢稀疏标签；用户尺度已满足但可选超严诊断失败。

## T5 未见真实资产

由评估者另供未见资产与要求，实际优化、导出、重导入并按对应路线验收。有实时要求时需真实设备配对帧数据；有蒙皮/表情时需动作测试；点云需覆盖和下游检查。未提供资产或环境时标未执行。T1–T4不足以证明技能提升实际优化效果。
