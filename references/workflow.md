# 工作流：先确定数什么，再决定怎么减

## 1. 冻结与最小契约

从当前文件和用户已有选择提取：输入/输出格式、目标引擎/管线、单位、原点/轴向/层级、必须保留的逻辑零件及交互、允许的外观变化和观察尺度、数量/资源上限、目标设备和帧要求。没有FPS明示要求时，不擅自把60FPS变成硬门槛。原有严格阈值与最新实际用途分开记，按用户最新契约判定。

原始文件与依赖只读冻结SHA256。先验证无优化往返：直接读取、引擎导入、Blender导入可能各自清理重复面或拆点。建立源零件ID→路径/变换/材质→候选顶点三角范围映射。映射保留不等于点选、拆装已正常。

为新试验建新目录。缓存用于筛选与重组，不当作从头运行全部算法的证据。保存工具版本、参数、种子、输入/输出哈希和被拒绝的候选原因。大工程/Library写入有足够空间的位置；不自动清理旧证据。

## 2. 计数表

| 数字 | 口径 | 常见陷阱 |
|---|---|---|
| FBX控制点 | 源Geometry坐标点 | 不是Unity渲染顶点 |
| polygon | 源多边形 | 不等于最终三角面；n-2是普通简单多边形的计数估计，复杂/退化面以导入器实际结果为准 |
| 引擎顶点 | 实际vertex buffer | 硬法线、UV、颜色、切线会拆点 |
| 唯一网格 | 每份Mesh资产一次 | 不含多实例成本 |
| 实例展开 | 每个实际实例的点面求和 | 嵌套prefab需展开；共享Mesh不等于只画一次 |
| 子网格引用 | 各primitive实际引用的顶点数求和 | 不同子网格可重复引用相同顶点；不等于空间去重 |
| 材质 | 唯一对象、.mat文件、槽位引用分别记 | 1材质不必然1 Draw Call |
| 资源字节 | 实际运行依赖闭包 | ZIP大小、Player大小、预览HTML大小不是模型依赖大小 |

MeshCollider不重复加到视觉面数里，但物理网格与碰撞成本单列。隐藏、禁用、LOD与活动状态注明。渲染器、MeshFilter、SkinnedMeshRenderer和Mesh资产分别计数。参考文件与老师检查器不完全吻合时，把口径写作推断，不按有利数字改上限。

GLB统计要遍历所选scene与节点实例。`audit_glb.py`只检查JSON声明和普通节点层级；它不读取索引值/解码压缩，不展开`EXT_mesh_gpu_instancing`，不能出具几何有效或目标设备接受结论。重复POSITION accessor按primitive求和会重复记点。

## 3. 从一件试到整板

选代表性结构而非只选最好减的：板/孔、薄引脚、弯折金属、螺丝/弹簧、插座/FPC、浮雕标识。每件准备少量明确不同候选；先检查局部几何与特写，再做整板预算组合。

几何拓扑和渲染角点属性分开：可用位置邻接识别表面，但输出时恢复法线/UV/颜色硬缝。去重比较完整属性，不跨逻辑零件合点。删除未引用顶点必须压紧所有属性流、重映射所有索引；不能只改positions。缓存优化、压缩和LOD分别计成果，不冒充几何减面。

建立每个零件候选表：点、面、依赖字节、材质/绘制、局部误差、图像、性能、状态。一件的高保真修复超出总余量时，先定位真正可省的部位，再成对试验。一个零件有可行样本不等于可以批量复制到全部重复件。整数选择/启发式可用于组合，超时或当前候选集无解不证明所有表示无解。

## 4. 校验分层

1. 结构：ID、根变换、单位、包围盒、孔/边界、薄壁/间距、接触端点、材质和属性；源已有缺陷与新增缺陷分开。
2. 几何：固定种子、双向表面采样，加上边界/边中点/面心、薄件端点和局部区域；全局与局部各报。采样最大值不是严格Hausdorff上界。最小件应使用本件尺度，不能用整板尺度遮盖误差。
3. 图像：相同相机、分辨率、灯光、曝光、色空间、PBR与背景；至少轴向、斜视及有功能意义近景；标注真实观看尺度。轮廓IoU与物体前景RGB误差分开。空前景样本判无效，不能因两张都是空白计通过。人工检查独立记录。
4. 性能：按performance.md；全板通过不覆盖近景；新候选不自动继承旧候选实测。
5. 交付：实际导出目标格式→空工程导入→实际渲染→再次计数及依赖；blend要重开，启动器要真打开目标文件而非默认立方体。

## 5. 依赖、引用与交付

运行闭包包括Mesh、prefab、场景（若要求预览）、材质、shader、递归include/.cginc、贴图以及必要文件/文件夹meta。自动GetDependencies可能漏显式include，需核对。标准unitypackage的meta与私有引擎编码meta不同，不截断未知GUID；无法识别的记录单独保留unknown计数。

包导入与直接复制Assets目录分别验证；成功一种不能代替另一种。合并Renderer时保持教学语义层/碰撞层，实际检查高亮、选择、拆装、动画、脚本引用和碰撞；缺工程可继续模型实验，交互状态填null。对Unity专用shader模型与真几何GLB/blend分别导出计数。标准GLB不能执行Unity shader。

最终包用相对路径、离线可用入口和缺文件明确失败。ZIP做CRC和逐文件SHA256核对；单次保存成功不是可用证明。只在全部**用户所需**检查有证据时称“在已测范围验收通过”；否则称工作候选/人工审看候选，给出具体缺口。
