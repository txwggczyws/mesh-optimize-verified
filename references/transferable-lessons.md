# 可迁移的优化经验

| 观察或失败 | 应改变的决策 | 保留的证据 |
|---|---|---|
| 同一模型在不同工具中点数不同 | 区分源控制点、角点属性拆分、渲染流、唯一资产和实例展开；以所需导出格式重新导入验数 | 导入设置、每格式计数与依赖 |
| 比例请求满足但孔、薄壁或接触受损 | 限制受影响区域，保留必要拓扑；考虑结构重建而非继续加大比例 | 局部失败图、边界和尺寸对照 |
| 修好一处却超总预算 | 测新贡献减旧贡献，组合后重新计数；寻找真正可省区域，保留不可简化部位 | 候选组合表、全资产预算 |
| 反光错误被误认为形状损失 | 零降面往返先定位法线、切线、材质或变换；不调灯隐藏错误 | 原/往返/候选相同条件截图 |
| 面少但顶点仍多 | 检查未压紧流、硬缝及材质拆点；完整属性去重，最终索引确定后压紧所有流 | 真实顶点缓冲、属性与重映射结果 |
| 更少几何却更慢 | 检查片元、过绘制、shader、提交、皮肤变形和加载；只对真实瓶颈做单因素试验 | 完整资产与近景的同条件帧数据 |
| 截图一样但性能不同 | 正确性与性能分别验证；同图不能证明相同运行成本 | 图像证据与新候选独立帧数据 |
| 空白渲染、计时无效却显示超高 FPS | 检查实际资产像素、绘制与计时器有效性；无效测量不算零成本 | 无效记录和修正后实测 |
| 全局均值好但关键细节差 | 按部位、视角、姿态和运行块报告，增加独立留出检查 | 最差区域与极值，不隐藏失败 |
| 标准格式无法复现专用 shader 表示 | 各表示独立导出、计数和渲染，必要时保留真几何备用 | 各格式验证，不能继承另一表示的结论 |
| 保存成功但另一机器缺引用 | 从干净环境验证运行依赖闭包和入口；相对路径与哈希清单随包 | 实际重开/导入结果、缺失依赖清单 |

这些经验用于选路与诊断，不把旧资产的数值阈值、工具组合、验收结果或设备表现变成新任务的默认标准。
