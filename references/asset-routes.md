# 按资产与用途选路线

以下为可采用的方法与必须验证的条件，不是随包脚本已经实现的功能。先确认输入属于多边形网格、解析曲面、点云或其他表示；格式扩展名不能替代内容检查。体积、隐式表面、毛发等表示需要对应工具；不可声称静态网格脚本直接支持。

| 资产/用途 | 优先路线 | 额外验收 |
|---|---|---|
| 静态硬表面、装配 | 按结构分件；属性感知 QEM；平面轮廓重三角化；必要时解析截面重建 | 孔、薄壁、端点、间隙、轴心、硬边、零件 ID 与选择/拆装 |
| 带贴图道具、环境物 | 保 UV 接缝和材质边界的简化；法线/切线保持或一致重烘焙 | UV 拉伸、纹理密度、切线空间、法线贴图、透明边缘；禁以模糊贴图掩盖形变 |
| 角色、蒙皮、表情 | 使用显式支持蒙皮/形态键的简化或重拓扑工具；必要时权重转移与重烘焙 | 骨骼/绑定、权重归一、关节极限姿态、表情极值及组合、三角翻转与穿插；原顶点索引依赖重映射 |
| 扫描、雕刻、自然表面 | 按需要清理；属性简化；较大降幅时重拓扑与细节烘焙 | 小组件是否为真实特征、表面覆盖、薄片、颜色/UV恢复；清理缺陷需与优化损失区分 |
| 大型场景、建筑、地形 | 分块/实例共享/LOD，再按局部预算简化；边界共享约束 | 块接缝、远近景切换、加载峰值、遮挡、导航/碰撞及实例展开成本；不能焊死独立逻辑物体 |
| 解析 CAD 曲面 | 有可用曲面源时优先调整弦高/角度/边长的镶嵌；只有网格时受约束简化/重建 | 尺寸、曲率、单位和面连接；网格减少不等于保留 CAD 参数化设计历史 |
| 点云 | 体素采样、均匀/随机/最远点采样或分区自适应采样，按任务比较 | 点数、密度、稀疏部位覆盖、边界/法线/颜色/标签；用双向距离和下游任务结果检查；不套三角面指标 |
| LOD/实时渲染 | 每级独立生成与验收；按屏幕误差选择切换；缓存/fetch/实例与压缩按瓶颈使用 | 层级切换跳变、跨块裂缝、内存总量、动画一致性和最差视角；LOD 不代替基础资产要求 |

预算与参数：定义目标顶点、三角面、内存、绘制和误差；从少量保守参数开始，对照可达数量与质量形成候选表，选择可行的折中。某算法在保护约束下停滞时，考虑保留原件、局部重建、预算调配或不同表示；不直接关闭全部保护。

带动画资产的纯静态形状通过不能代表动作通过。没有支持相应属性的工具时，保留原件、提出适配路线或可执行交接；不要为了完成减面而删除动画。
